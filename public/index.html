📲 Installer OmniSMS

Installez OmniSMS sur votre appareil pour une expérience native.

⚠️ Ces instructions nécessitent le navigateur Safari sur iPhone/iPad.
1
Ouvrir dans Safari Ouvre OmniSMS dans Safari (pas Chrome ni Firefox).
URL : omnisms.vercel.app
🌐
2
Appuyer sur Partager Appuie sur l'icône Partager en bas de Safari (carré avec flèche vers le haut).
⬆️
3
Faire défiler les options Fais défiler la liste d'options vers le bas jusqu'à voir « Sur l'écran d'accueil ».
📋
4
Appuyer sur « Sur l'écran d'accueil » Appuie sur cette option, puis confirme le nom OmniSMS.
📱
5
Appuyer sur « Ajouter » Confirme en appuyant sur Ajouter en haut à droite. OmniSMS apparaît sur ton écran d'accueil ! 🎉
✅
📇 Comment obtenir un fichier VCF ?

Le fichier .VCF contient vos contacts. Choisissez votre téléphone pour voir les étapes.

💡 Une fois le fichier .vcf obtenu, revenez ici et cliquez sur 📱 Importer contacts pour le sélectionner.
🍎 iPhone — 2 méthodes selon vos besoins

Méthode 1 : Un seul contact (rapide)

1
Ouvrir Contacts Ouvrez l'app Contacts sur votre iPhone.
👤
2
Choisir le contact Touchez le contact que vous voulez exporter.
👆
3
Partager le contact Faites défiler vers le bas → Partager le contact → Enregistrez le fichier .vcf dans Fichiers.
📤

Méthode 2 : Tous les contacts (recommandé)

1
Aller sur iCloud.com Sur un ordinateur, ouvrez iCloud.com et connectez-vous avec votre Apple ID.
💻
2
Ouvrir Contacts Cliquez sur Contacts.
📇
3
Tout sélectionner Appuyez sur Ctrl + A (Windows) ou Cmd + A (Mac) pour tout sélectionner.
✅
4
Exporter vCard Cliquez sur l'engrenage ⚙️ en bas à gauche → Exporter vCard. Le fichier .vcf est téléchargé.
💾
5
Importer dans OmniSMS Revenez dans OmniSMS → Contacts → 📱 Importer contacts → choisissez le fichier.
🎉
ℹ️ Selon votre version iOS, les noms de menus peuvent varier légèrement. Vous pouvez aussi utiliser l'app gratuite My Contacts Backup sur l'App Store.
🤖 Android — via Google Contacts
1
Ouvrir Contacts Ouvrez l'app Contacts ou Google Contacts sur votre téléphone.
📇
2
Ouvrir le menu Appuyez sur votre photo de profil en haut à droite ou sur les 3 lignes ☰ → Paramètres.
☰
3
Exporter Faites défiler vers le bas → Exporter ou Exporter les contacts.
📤
4
Choisir et enregistrer Sélectionnez le compte (si demandé) → Appuyez sur Exporter vers fichier .vcf → Enregistrez dans Téléchargements.
💾
5
Importer dans OmniSMS Revenez dans OmniSMS → Contacts → 📱 Importer contacts → choisissez le fichier .vcf depuis Téléchargements.
🎉
ℹ️ Sur certains téléphones (Samsung, Xiaomi...), l'app s'appelle Contacts et l'option peut être dans Gérer les contacts → Importer/Exporter. Le principe reste le même : cherchez Exporter au format .vcf.
